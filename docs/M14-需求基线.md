## 二、实现要点

1. **dark token 覆盖**：在 `app.css` 末尾新增 `html.dark { ... }`，仅覆盖变量值（颜色族：品牌/背景/表面/边框/文本/语义四色），组件类（`btn`/`card`/`table`/`banner` 等）无需改动即自动适配。
2. **导航按钮样式**：`.site-nav button` 与既有 `.site-nav a` 同风格（深底浅字、hover 半透白）。
3. **防闪烁**：`base.html` `<head>` 内联脚本在渲染前读取 `localStorage['hpsl-theme']`，为 `dark` 时即给 `<html>` 加 `dark` 类，避免白屏闪一下。
4. **切换按钮**：头部 `主题：深色/浅色` 按钮，`onclick` 调 `hpslToggleTheme()` 切换 `<html>` 的 `dark` 类并写回 localStorage；`hpslSyncThemeLabel()` 同步按钮文案。
5. **概念图适配**：`graph.html` 的节点文本、边标签、图例文字改走 `var(--text)`/`var(--text-muted)`，深色下仍可读；节点圆点/状态着色由 JS 按 `verify_status` 着色，不受影响。
