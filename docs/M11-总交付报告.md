## 2. 批次2：密钥静态加密持久化

### 2.2 实现要点（对应 `docs/M11-批次2-3-需求基线.md` D-M11-4）
- 新增固定盐 `MASTER_SALT = b"hpsl-static-enc-v1"`（非随机、不落盘，保证同机可复现解密）。
- 新增 `_default_passphrase(secrets_dir)`：环境变量 `HPSL_MASTER_PASSPHRASE` 优先；否则按 `sha256(str(secrets_dir)+":hpsl-v1")` 确定性派生。
- `FileBackend.__init__` 默认 cipher 改为：`cryptography` 可用时 → `FernetCipher(derive_fernet_key(_default_passphrase(...), salt=MASTER_SALT)[0])`；仅在 `cryptography` 真正缺失时回退 `PlaintextCipher()`（保留降级告警，与现状一致）。
- `keyring` 仍为最高优先级后端（顺序不变）。

### 2.3 纪律守住
- 零 DDL（仅改密钥文件加密方式，未触 16 库对象）。
- 无新错误码。
- 密钥红线（D1 §6.5）：密钥不进库、不全文返回、不随导出；`key_status` 仅 `has_key/stored_in/key_tail`（后4位）。
- 引擎 headless 不变；`secrets` 不反向依赖 routes/app/fastapi（import 守卫保留）。

### 2.4 验收（本批次 + 终验）

- Fernet 往返正常；落盘文件不含明文 `sk-`。
- `test_file_backend_fernet_if_cryptography_available` 由 skip 转 PASS（+1）。
- 既有密钥测试全过；整库零回归。

## 3. 批次3：Markdown 导出

### 3.1 新增 / 改动文件
- 新增 `hpsl/routes/export.py`、`hpsl/templates/export.html`。
- 改动 `hpsl/app.py`（挂载 export api+page router，置于 wizard 之后，**中间件顺序未变**）、`hpsl/routes/__init__.py`（加入 `export_routes`）。

### 3.2 端点
- `GET /export`（read_security）：导出页；无激活项目显示「尚未选择项目」提示。
- `POST /api/v1/export/{kind}`（**write_security**，与备份 POST 一致）：
  - `kind ∈ {project, units, ledger, concepts}`；未知 → `C400001`。
  - 无激活项目 → `A080002`（既有码复用）。
  - 经 `db.safe_path(pid)` 防目录穿越（C400002）。
  - 生成 `.md` 落 `cfg.project_dir(pid)/"exports"/{kind}-{utc}.md"`，权限 0600。
  - 返回 `ok({"file","path","bytes"})`。

### 3.3 导出内容（读 `db.query`，零 DDL，仅外部文件）
- `project`：name / goal / initial_belief / created_at + 配置摘要（config JSON 无密钥）。
- `units`：单元列表与状态。
- `ledger`：四本账摘要（audit_log / gap / gap_candidate / claim_check / review / llm_call 等）。
- `concepts`：concept + concept_edge。
- 安全：不读取、不输出 `hpsl.secrets` 或任何 API key。

### 3.4 防密钥泄露（`_scrub`）
- `_SECRET_PATTERNS`（export.py:49）：
  - `sk-[A-Za-z0-9_-]{8,}`、`gAAAAA[A-Za-z0-9_-]{16,}`、`(?i)\bBearer\s+...`、`(?i)\b(Cookie|Set-Cookie)\s*:\s*...`
- `_scrub(text)`（export.py:57）遍历替换为 `[REDACTED]`；各 `_build_*_md` 末尾均 `return _scrub("\n".join(lines))`。
- 仅针对密钥/令牌特征串，对正常学习文本误伤风险低。

### 3.5 纪律守住
- 零 DDL：仅读库 + 写外部文件；`count_user_objects(pid) == 16` 守护（export.py:10）。
- 错误码仅复用 `C400001` / `A080002`（及 `C400002` 防穿越）。
- 安全分层：页 read_security、导出 POST write_security。
- 中间件顺序不变；引擎 headless 不变。
- **密钥不随导出**。

### 3.6 验收（本批次 + 终验）
- 每 kind 导出 `.md` 含预期标题且 `"sk-" not in content`（AC2，9 例全过）。
- `count_user_objects(pid) == 16` 守护通过。
- 整库零回归。
