## 1. 模块定位（§3.2.M10.1）

M10 在 **M1 已建 Web 骨架**之上，将 **M9 治理度量经 REST 暴露**，并落地：账本总览四平面视图、软提示关闭、traceId 中间件、`/readyz`、`/healthz`、优雅停机。

**范围澄清（关键）**：M1 已实现 Web 骨架（FastAPI app + 安全中间件 + projects 路由 + 模板 + result/error），故 M10 真实增量并非重做安全/项目 CRUD，而是：
- M9 治理度量经 REST 暴露（4 端点）；
- 账本总览四平面视图（`/ledger` 页面）；
- 软提示关闭（进程内按会话记忆）；
- `TraceIdMiddleware` + `/readyz` + BizError 携带 traceId + 优雅停机。

**重业务页面**（`/unit`、`/unit/judge`、`/unit/gaps`、`/unit/integrate`、`/review`、`/settings`、`/wizard`）、**备份导出**（F1，`/api/v1/projects/{pid}/backup` 当前 501 占位）、**卡片与概念图 UI**、**超限确认弹层**（A080001 消费 M8 budget_status）列为后续 **Phase B/C**，本里程碑不做。

## 2. REST 端点（§3.2.M10.2）

| 方法 | 路径 | 安全依赖 | 用途 | 纪律 |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/counts` | `read_security` | 四平面计数指标全量（M9 `compute_counts` 读时重算） | 只读，零 DDL |
| GET | `/api/v1/counts/planes` | `read_security` | 四平面度量 + 按平面分组的软提示 | 只读，零 DDL |
| GET | `/api/v1/soft-prompts` | `read_security` | 当前活跃软提示（种 `hpsl_sid` cookie） | 只读，零 DDL |
| POST | `/api/v1/soft-prompts/{id}/dismiss` | `write_security` | 关闭软提示（进程内按会话记忆，非持久） | 仅改进程内 `_dismissed` 字典 |
| GET | `/ledger` | `read_security` | 账本总览页（Jinja2 + HTMX 渲染） | 只读，零 DDL |
| GET | `/healthz` | 无 | Liveness，返回 `phase="M10"` | — |
| GET | `/readyz` | 无 | Readiness，`projects_root` 可读写则 200，否则 503 | 纯探测，不建目录 |

> 页面路由（无前缀）与 API 路由（`/api/v1`）分别挂载；备份导出 F1 仍为 M1 遗留 501 占位。

## 3. 安全基线（沿用 M1 冻结项 #5）

- **中间件顺序**（Starlette 语义：最后添加者最外层）：`SecurityMiddleware` 在内，`TraceIdMiddleware` **最外层包裹**。traceId 最外层 → 请求最先经它生成/透传 `trace_id`，安全层拒绝（如 Host 非白名单 C400003）的响应也会回写 `X-Trace-Id`，保证拒绝路径同样可观测（贯穿全程）。
- **读接口**：Host 白名单 + 限流（process / route）。
- **写接口（dismiss）**：Origin 回环校验 + CSRF 双提交 + 限流（process / route / write_freq）。
- **错误码复用**：`A010001`（未激活项目）、`C403001`（来源不被允许）、`C429001`（限流）、`C400003`（Host 不在白名单）。**M10 无新码空间**。

## 4. traceId（§3.2.M10.5 Step1）

- `new_trace_id()`：返回 `secrets.token_hex(16)`（32 位 hex）。
- `TraceIdMiddleware`：读 `x-trace-id` 头或生成，置 `request.state.trace_id`；响应头回写 `X-Trace-Id`。
- `BizError` 异常处理器携带 `trace_id` 回显（`fail(code, trace_id=...)`）。

---

## 5. 账本总览（`/ledger`）

- 消费 **M7 `ledger_summary`**（四本账：缺口 / 单元 / 卡片 / 概念 / 概念连线 / 活跃复测）+ **M9 `compute_counts` / `plane_signals`**（四平面度量 + 软提示）。
- 页面三段：**四本账**（grid 卡片）、**四平面度量**（12 项 CountsVO 字段）、**治理软提示区**。
- **软提示一键关闭**：`hx-post` 至 dismiss 写接口（`hx-swap="none"` + `htmx:after-request` 移除 DOM）；服务端进程内按 `sid` 记忆关闭，整页刷新依 cookie 过滤（与写接口共享 `_dismissed`）。
- **无激活项目** → 显示「尚未选择项目，请先在首页选择或新建项目」提示（不渲染四本账/四平面）。

## 6. 优雅停机

- `serve()` 改用 `uvicorn.Server(Config(..., timeout_graceful_shutdown=30))`：SIGTERM/SIGINT → 停止接入新流量 → 处理在飞请求 ≤30s。
- `atexit.register(db.close_all)`：释放全部项目写连接（隐含 WAL checkpoint），保证本地库持久化。

---

## 7. 纪律守住（M0 冻结约束）

- **零 DDL**：M10 仅新增只读端点与页面，不新增/改动任何表或列；`count_user_objects == 16` 经既有 `test_governance_zero_ddl` 守护。
- **`write` 唯一写入口**：M10 路由全部只读（dismiss 仅改进程内 `_dismissed` 字典，不触达 `db.write`）；`close_all` 仅关连接。
- **错误码分段**：M10 无新码空间；缺失项目回退失败用 `A010001`。
- **隔离红线（O13）/ 密钥红线（D1 §6.5）**：不涉及。
