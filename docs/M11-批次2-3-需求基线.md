## 一、批次2：密钥静态加密持久化（消除「明文密钥保险库降级」告警）

### 目标
密钥文件落盘**静态加密（Fernet）**，默认不再触发 `PlaintextCipher` 的 RuntimeWarning；保留全部纪律红线。

### 范围边界
- **仅改** `hpsl/secrets/keystore.py`（及必要的内部 helper）。
- 不动路由 / db / models(除已新增查询外) / config / app.py / 引擎 / 测试基座。
- 依赖 `cryptography` + `argon2-cffi` **已装**（managed venv）。

### 主理人决策（D-M11-4）
- FileBackend **默认 cipher**：`cryptography` 可用时 → `FernetCipher(derive_fernet_key(passphrase, salt=固定盐)[0])`；
  `cryptography` 缺失 → 保留 `PlaintextCipher`（降级告警不变，与现状一致）。
- **passphrase 来源**（优先级）：
  1. 环境变量 `HPSL_MASTER_PASSPHRASE`（用户自设，最强）；
  2. 未设 → 按 `HPSL_HOME` 路径 + 固定应用盐**确定性派生**（`hashlib.sha256(str(secrets_dir).encode()+b":hpsl-v1")`）。
     - 权衡：本地单机威胁模型，保护密钥文件不被明文泄露/备份外泄；"秘密"为代码+路径，文档显式标注。
- **盐**：固定常量 `MASTER_SALT = b"hpsl-static-enc-v1"`（非随机、不落盘），保证同机多次运行可解密。
- `keyring` 仍为最高优先级后端（顺序不变）。

### 纪律约束（硬）
- 零 DDL：仅改密钥文件加密方式，不触 16 库对象。
- 错误码复用：无新码。
- 密钥红线（D1 §6.5）：密钥不进库、不全文返回、不随导出；`key_status` 仅 `has_key/stored_in/key_tail`。
- 引擎 headless 不变；`secrets` 不反向依赖 routes/app/fastapi（import 守卫保留）。

### 验收
- `PlaintextCipher` 告警在 cryptography 可用且未设 env 时**不再出现**（默认 Fernet）。
- 既有密钥测试全过；`test_file_backend_fernet_if_cryptography_available` 由 skip 转 PASS。
- 全量 pytest 零回归。

## 二、批次3：Markdown 导出（项目 / 单元 / 账本 / 概念）

### 目标
将项目 / 单元 / 账本 / 概念导出为 `.md`，写入项目 `exports/`。**绝不**包含任何密钥。

### 范围边界
- 新增 `hpsl/routes/export.py` + `hpsl/templates/export.html`。
- 挂载：app.py（api + page router）+ routes/__init__.py。
- 不改动 secrets/keystore.py（批次2 领地）、引擎核心、中间件顺序。

### 端点
- `GET /export`（read_security）：导出页（无激活项目显示「尚未选择项目」提示）。
- `POST /api/v1/export/{kind}`（**write_security**，与备份 POST 一致）：
  - `kind ∈ {project, units, ledger, concepts}`；未知 → `C400001`。
  - 无激活项目 → `A080002`（既有码复用）。
  - 生成 `.md` 落 `cfg.project_dir(pid)/"exports"/{kind}-{timestamp}.md"`（0600）。
  - 返回 `ok({"file","path","bytes"})`。

### 导出内容（读 db.query，零 DDL，仅外部文件）
- **project**：name / goal / initial_belief / created_at + 配置摘要（config JSON 无密钥）。
- **units**：单元列表与状态（unit 表列）。
- **ledger**：四本账摘要（audit_log 等；含 gap 若 schema 有）。
- **concepts**：concept + concept_edge。
- 安全：不读取、不输出 `hpsl.secrets` 或任何 API key（`sk-` 类字串不得出现）。

### 纪律约束（硬）
- 零 DDL：仅读库 + 写外部文件；`count_user_objects(pid) == 16` 守护。
- 错误码复用：仅 `C400001` / `A080002`（或 `A010001` 若存在性检查）。
- 安全分层：页 read_security、导出 POST write_security。
- 中间件顺序不变；引擎 headless 不变。
- 密钥不随导出。

### 验收
- 每 kind 导出 `.md` 含预期标题且不含密钥字串（如 `sk-`）。
- `count_user_objects(pid) == 16` 守护。
- 全量 pytest 零回归。
