## 1. 实现要点

- **`hpsl/routes/stats.py`**：
  - 新增 `_ALLOWED_RANGES = (7, 30, 90, 180)` 与 `_parse_range(s)`（非整数/越界→30）。
  - `compute_stats(pid: str, days: int = 30)`：时间序列日期序列改为动态 `range(days-1, -1, -1)`，本地列表重命名为 `day_labels` 避免遮蔽参数；复用既有 `now`（UTC）。其余聚合（cost_max、unit_breakdown）不变。
  - `stats_page(req)` / `stats_api(req)` 读取 `?days=` → `_parse_range` → 传入 `compute_stats`；页面 context 附带 `days` 供高亮。
- **`hpsl/templates/stats.html`**：标题 `花费趋势（近 {{ days }} 天）`；新增 `.range-links` 区间链接（7/30/90/180，`class="active"` 高亮当前）；无记录文案同步 `days`。
- **`hpsl/static/app.css`**：新增 `.range-links` 与 `.range-links a.active` 样式（含 `html.dark` 覆盖）。
