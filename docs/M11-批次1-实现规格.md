## 1. 密钥 REST 暴露（§3.2.M4 接口清单）

新增 `hpsl/routes/settings_keys.py`（api_router prefix `/api/v1`）：

| 方法 | 路径 | 安全 | 用途 | 纪律 |
| --- | --- | --- | --- | --- |
| GET | `/settings/keys` | `read_security` | 列出已知 Provider 的密钥状态（仅 `has_key`/`stored_in`/`key_tail`） | 只读，零 DDL |
| PUT | `/settings/keys/{provider}` | `write_security` | 写入 provider 密钥（`secrets.set_api_key`，经 keyring 或 Fernet 文件） | 仅改进程外密钥存储，不触 DB |
| POST | `/providers/{name}/test` | `write_security` | 测试连接（`test_connection`） | 仅出站探测，零 DDL |

- `PUT` 入参：`{"key": "<str>"}`；`provider` 须为 `registry` 已知 Provider（否则 `C400001`）。
- 密钥存储目录：`config.home() / "secrets"`（落在 `HPSL_HOME` 内，随测试临时目录隔离，**不污染源码包目录**），经 `secrets_dir=` 透传。
- **零 DDL**：密钥不进 `project.db`；`count_user_objects == 16` 守护仍成立。
- **错误码复用**：缺参/非法 → `C400001`；密钥缺失 → `A040003`（已在 `secrets` 定义）。**无新码空间**。

## 2. `test_connection` 落地（§3.2.M4 接口 `test_connection(provider) -> bool`）

新增 `hpsl/models/connectivity.py`：

- `test_connection(provider, *, secrets_dir) -> dict`：
  1. 取密钥：`secrets.get_api_key(provider, secrets_dir=secrets_dir)`；缺失 → 返回 `{"ok": False, "detail": "密钥缺失或无效", "code": "A040003"}`。
  2. 按 provider 构造最小探活请求（短超时 5s）：
     - `openai_compat`：`GET {base_url}/models`，`Authorization: Bearer <key>`。
     - `anthropic`：`GET {base_url}/models`，`x-api-key: <key>`。
     - `gemini`：`GET {base_url}/models?key=<key>`。
  3. 返回：`{"ok": bool, "detail": str}`。`200<=status<500 且非 401/403` → ok=True；`401/403` → ok=False（密钥无效）；任何异常/超时 → ok=False（网络不可达）。**绝不抛未捕获异常**（离线安全）。
- 使用 `httpx`（项目已依赖，FastAPI TestClient 自带）。

## 3. 首次启动向导 `/wizard`（UC-04）

新增 `hpsl/routes/wizard.py`（page_router）`GET /wizard`（`read_security`）；新增 `hpsl/templates/wizard.html`（extends base）：

四步引导（纯前端 fetch 编排，复用既有 API）：
1. **建项目**：name/goal/initial_belief → `POST /api/v1/projects` → `POST /api/v1/projects/{id}/switch`。
2. **填 key**：Provider 下拉（取自 `GET /settings/keys` 或 `registry.list_xxx`）→ `PUT /settings/keys/{provider}`。
3. **测连接**：`POST /providers/{provider}/test` → 展示 ok/detail。
4. **完成**：链接至 `/unit` 与 `/ledger`。

- 页面 `read_security`；写入均走既有写接口（write_security 由接口自身校验）。
- 无激活项目时显示「尚未选择项目」提示（与 `/ledger`/`/settings` 一致）。
- `base.html` header 增加「向导」链接；`index.html` 在无项目时增加醒目「首次启动向导」入口。

## 5. 纪律守住（M0 冻结约束）

- **零 DDL**：密钥落 `HPSL_HOME/secrets/` 文件，不触 16 库对象；`count_user_objects == 16` 经测试守护。
- **`write` 唯一写入口**：密钥写入由 `secrets.set_api_key` 负责，不经 `db.write`（密钥红线 D1 §6.5：密钥不进库）。
- **错误码分段**：仅复用 `C400001` / `A040003`；无新码。
- **引擎 headless 不变**：仅新增 `models/connectivity.py`（M4 能力暴露），不动状态机/判分/四本账。
- **安全分层**：页面 `read_security`；密钥写/测试 `write_security`（Origin + CSRF + 限流）。
- **隐私红线（D1 §6.5 / §7.2.3）**：密钥尾 4 位脱敏；`GET /settings/keys` 绝不返回完整密钥；密钥禁止随导出（本批次无导出）。

## 6. 验收（AC）

- **AC1**：`GET /wizard`（激活项目）→ 200；含四步引导结构。
- **AC2**：`PUT /settings/keys/{provider}` → 200；密钥写入 `HPSL_HOME/secrets/` 且 `GET /settings/keys` 返回该 provider `has_key=true` + `key_tail` 后 4 位。
- **AC3**：`GET /settings/keys` → 200；仅暴露 `has_key`/`stored_in`/`key_tail`，无完整密钥。
- **AC4**：`POST /providers/{name}/test` → 200；离线/异常 → `ok=false` + 非崩溃；密钥缺失 → `A040003`。
- **AC5**：零 DDL（`count_user_objects == 16`）；无 `db.write` 直写密钥。
- **AC6**：v0 封版——全量 `pytest` 仍全绿（277 → 277+N，零回归）；Phase 5 白盒 6 项 PASS。
