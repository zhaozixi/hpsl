## 1. 里程碑概述

M3 = 锁定基线 **F3（角色与隔离）/ BD-3（角色与隔离域）/ BC-3（角色隔离上下文）** 的后端引擎落地。交付**无界面引擎层** `roles/contracts.py`（六角色契约 allow 元组，Shared Kernel C-04）+ `roles/assembler.py`（白名单组装器 `assemble()` + 输入预览 `preview()`）+ `roles/prompts/` 六角色提示词骨架（M4/M7 填充）。

**核心卖点（基线 O13）固守**：每个 LLM 角色只能看到自己契约 `allow` 白名单内的字段；**答案机输出（`answer_machine_output`）永不流入任何消费角色**（出题者 / 提问者 / 挑错者 / 选题 / 书记员），避免同源污染与确认偏误。这是产品差异化护城河，M3 以可断言方式（契约层哨兵 + 组装层白名单 + 测试强断言 + AST 守护）三重固守。

**零 DDL 变更**：复用 M0 既有库；复用 `common/enums.Role`（六角色枚举）、`common/errors.A030001`（契约越界，M3 错误码已预注册）。

**范围边界（SOP 范围冻结）**：M3 不做 UI/交互（Phase 2/3 不适用）、不做 LLM 真实调用 / Provider 适配 / 密钥管理（归属 M4/M7）、不落实判分域（归属 M4/M5）、不做 HTTP 路由暴露（归属 M10）。

## 6. 主理人裁决/确认

| 项 | 结论 | 落地 |
|---|---|---|
| M3 错误码 | 复用预注册 `A030001`（契约越界：角色读取未授权字段），不新增冲突码 | `errors.py` 已注册；`assembler._contract` 越权/未知角色统一抛 A030001 |
| `allow` 数据结构 | 用**有序元组**（非 set/list），保证组装顺序稳定与可断言 | `contracts.py` 全部 allow 为 `tuple` |
| 隔离不变量强度 | 采用导入时 `assert` 硬失败（优于规格"告警"措辞），阻断加载即暴露泄漏 | `contracts.py` 模块级 `assert` |
| 越权语义 | "越权"定义为角色显式 `requested` 含 allow 之外字段即抛错；白名单默认静默剔除非允许字段（安全默认） | `assembler.assemble` 实现 |

## 7. 质量结论

### **结论：无条件通过（Pass）**

- AC-M3-1~7 **全部满足**，对应 12 个 M3 用例全绿；
- 全量 77 用例 0 失败，M0/M1/M2 回归 65 绿（AC-M3-6）；
- **核心卖点（O13）固守**：独立对抗测试确认 `answer_machine_output` 在含该字段的 context 下，对**全部六角色**（含答案机自身）组装结果均不含该键；契约层 `assert` + 组装层白名单 + 测试强断言 + AST 守护四重保障；
- headless 纪律：AST 扫描确认 `roles/` 不依赖 `models`/`routes`/`app`/`db`，无 SQLite 写路径；
- 无 致命 / 严重 / 一般 级未闭环缺陷；两处轻微文档漂移已就地修复。
