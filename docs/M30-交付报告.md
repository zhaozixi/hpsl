## 2. 关键决策

| 编号 | 决策 | 理由 |
|---|---|---|
| D-M30-1 | 分词优先 jieba，缺失则「中文 bigram + 英文词」兜底 | 不引入新依赖（离线）；装 jieba 自动升级 |
| D-M30-2 | `chunk_fts.text` 存原文，MATCH 未命中再 LIKE 兜底 | 保证"检索展示原文"，中文无分词也能用 |
| D-M30-3 | 知识库只接受**绝对路径**，越界符号链接跳过 | 避免 cwd 相对路径歧义与根外读取 |
| D-M30-4 | 删除 source 在写锁内单事务 DELETE + 写 audit（`db.write` 不支持 DELETE） | 维持审计完整；已在代码注释说明 |
| D-M30-5 | 交叉验证每个模型各自记账 + 各自写 turn | 成本与回放都能按模型归因 |
| D-M30-6 | 衰减只读计算，不回写 `verify_status` | 避免与复测写回冲突（复测才是唯一写回方） |
| D-M30-7 | 周盘点批量接口先全量校验再写 | 任一非法值整体拒绝，不留半写 |
| D-M30-8 | keyring 用 fake 模块验证优先级 | 环境未安装 keyring，不能做真实钥匙环集成 |
| D-M30-9 | CSRF 重启后对无效旧 cookie 重签 | 否则重启即永久 403 |
