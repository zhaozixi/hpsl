## 二、批次1：备份自动轮转调度增强

### 实现要点
- **`db.rotate_all_backups(keep_daily=7, keep_monthly=12)`**：遍历 `projects.list_projects()`，对每个项目调用既有 `rotate_backups(pid)`（仅删外部 `project-*.db`，前缀/正则双重保护）。零 DDL、best-effort（缺失 backups 目录跳过）。
- **`serve()` 启动即轮转**：在 `server.run()` 前调用 `db.rotate_all_backups()`，实现「启动即清理过期快照」的无人值守效果。
- **周期定时轮转**：`serve()` 启动一个 daemon 线程，每 `HPSL_ROTATE_INTERVAL_SECONDS`（默认 21600 = 6h，env 可配）调用一次 `db.rotate_all_backups()`；经 `atexit` 停止。整段 try/except 包裹，失败仅记日志不影响主服务。
- **CLI 子命令**（`app.main` argparse）：
  - `hpsl rotate [--pid PID]`：立即轮转全部项目（或指定 pid），打印各项目删除数。
  - `hpsl backup [--pid PID]`：对全部（或指定）项目执行 `db.backup_project(pid)`（其内部已轮转），打印生成路径。便于外部 cron 调度。
  - `serve` 行为不变。

### 纪律约束（硬）
- 零 DDL：`rotate_all_backups` 仅删外部快照文件；`list_projects` 只读；`backup_project` 既有。16 库对象不变（`count_user_objects==16`）。
- 无新错误码：CLI 用进程退出码/打印，不新增 HTTP 端点（避免新错误码与中间件变更）。
- 中间件顺序不变：`app.py` 仅改 `serve()` 与 `main()`，未动 app 装配。
- 引擎 headless 不变；`app.py` 启动钩子不影响既有请求路径。
- 密钥/用户数据红线：轮转只删本系统 `project-*.db`，绝不碰 `project.db` 或密钥文件。

### 验收
- 新增测试：`rotate_all_backups` 在两个项目各造多份过期/在期快照，断言保留日7+月12、删除越界文件、且 `project.db` 不被删。
- 新增测试：`hpsl rotate` / `hpsl backup` 经 `app.main([...])` 调用不抛错、产出预期输出（在临时 HPSL_HOME 下）。
- 全量 pytest 零回归（298 → +新例）。

## 三、批次2：概念图交互再打磨

### 实现要点（纯前端 + graph.py 只读补字段）
- **`graph.py`**：节点 dict 增补 `verify_status`（来自 `concept.verify_status`，只读查询，零 DDL），供前端着色。
- **`graph.html` 交互增强**：
  1. 缩放控件：`+` / `−` / `重置` / `适配`(fit-to-screen) 按钮（替代仅滚轮）。
  2. 节点悬停提示：hover 显示概念名 + 验证状态（无需点击）。
  3. 搜索/筛选框：输入名称高亮匹配节点、淡化其余；回车聚焦首个匹配。
  4. 状态着色：节点圆点按 `verify_status` 着色（已验证=绿、未验证=灰、待验证=琥珀），图例同步。
  5. 高亮过渡：节点/边 `opacity`/`stroke` 加 CSS 过渡，交互更顺滑。
  6. 触控增强：双指 pinch 缩放 + 双击重置（移动端），与既有 pointer 平移共存。
- 保留既有 SVG 内联色值（图形渲染必要）。

### 纪律约束（硬）
- 零 DDL：仅读查询 + 上下文字段增补（不改表结构）；前端仅改 `graph.html`。
- 无新端点：`graph.py` 仅丰富 `/graph` 上下文，端点签名/数量不变。
- 中间件顺序、错误码、引擎 headless、密钥红线均不变。
- htmx/JS hook 不破坏既有 `selectNode`/`resetView` 行为。

### 验收
- 现有 `graph` 页面测试仍 200 且含节点渲染（文本不变）。
- 新增/扩展测试：断言 `/graph` 返回含新控件（缩放按钮、搜索框）与节点 `verify_status` 注入。
- 全量 pytest 零回归。
