# HPSL 学习管家 · 网站操作手册（面向普通用户）

> 写给第一次用、看不懂界面上那些词的朋友。全程不用懂技术，跟着做就行。
> 本手册与站内「帮助」页（`/static/help.html`）内容一致，可随时点导航栏「帮助」查看。
> 覆盖范围：当前站点 **17 个页面**（M23 初版为 14 个；M24–M35 陆续新增知识库、周盘点、项目详情等，本手册已同步）。

---

## 一、这是什么东西

HPSL 是一个**帮你自学**的小工具。你告诉它「想学会什么」（比如「学会 Python 数据分析」），它会把这个大目标拆成许多**小单元**，一步步带着你：**学 → 练 → 考 → 复习**。它还会帮你记账（花了多少 AI 费用）、记笔记（卡片）、画关系图（概念图），让你清楚自己学到哪了、哪里还不会。

一句话：它像一个私人学习教练，把「我想学会」变成「我真的学会了」。

---

## 二、第一次怎么开始（四步向导）

第一次打开，点导航栏的 **向导**，跟着四步走：

1. **创建项目**：填「项目名称」和「学习目标」。项目就是你想要学会的那件事。比如名称填「Python 数据分析入门」，目标填「能独立完成一份数据分析报告」。
2. **填写模型密钥**：选一家模型（可选 OpenAI / Anthropic / Gemini / DeepSeek / 通义千问 / 智谱 GLM / Moonshot(Kimi) / 豆包 共 8 家，见设置页下拉），把你的 **API 密钥** 粘进去。密钥相当于模型的「登录密码」，从哪里买模型，就在哪里拿。填完点「保存密钥」。
3. **测试连接**：点「测试连接」，看看密钥和网络通不通。出现「连接成功」就说明没问题。
4. **开始学习**：点「进入单元学习」，正式开始。后面的学习流程系统会自动带你走。

> 提示：密钥只存在你本地，不会上传给任何人。不确定怎么拿密钥？问给你模型账号的人，或看模型官网的「API 密钥」页面。

## 三、各个功能怎么用

### 项目切换与顶栏「当前项目」
所有学习数据都记在**一个项目**里（比如「Python 数据分析入门」）。页顶那条常驻横幅就是提醒你这个的：

```
当前项目：Python 数据分析入门 · 你的所有操作都记在这个项目里        切换 / 查看全部项目
```

- 想换项目：点横幅右边的「切换 / 查看全部项目」回到首页，在项目列表里点「**切换到此项目**」；当前正在用的那个会标「**当前**」。
- 项目详情页里也有「切换到此项目」按钮，看中哪个直接切。
- **重启后会自动回到你上次用的项目**，不用每次手点；横幅上写的就是它。若想每次从「未选择项目」开始，启动时加 `--no-restore`（或设置环境变量 `HPSL_NO_RESTORE_ACTIVE=1`）。
- 顶栏只在「已选项目」时出现；看到「尚未选择项目」就说明还没选，按上面的方式切一个即可。

### 项目详情 · 配置表
从首页点项目名进入项目详情，往下有一张「**生效配置**」表：把「设置」里的全局值和这个项目的单独覆盖合并后，用中文列成 9 行——通过阈值、高分/低分线、缺口上限、单次时长、零缺口比例、强行闭环比例、跳过产出比例、复测间隔、预算上限。每行都有「含义」一列说人话。

- 日常使用**不用改**这张表，看懂即可；真要调阈值请去「设置」。
- 最底下「查看原始配置（排障用）」默认收起，里面是给维护者看的原始数据，平时不用打开。
- 表里只读，不会因为多看一眼就改动任何东西。

### 单元
「单元」是你要攻克的一个个**小知识点**。列表里每个单元后面有个**彩色小标签**，表示它进行到哪一步（如「未开始 / 学习中 / 已完成」）。点单元名进详情。

第一次用先点「**新建单元**」：填单元标题（必填），难度档可选「稳妥 / 拉伸 / 回补」，点「创建单元」即可。

### 单元详情 · 推进学习
进去后看 **工作流**：系统告诉你「当前状态」，并给你一个**「推进到下一步」**的按钮。每做到一定程度，就点一下，把单元往前推。就像过关一样，一步步走到「已完成」。

单元详情里还有四块，按顺序用：
- **产出**：先动手做出点东西（一段代码、一份分析、一个结论），再进入验证；
- **记录一次尝试**：重述（固定三问）或边界题的自评 / 确认得分；
- **判定闭环**：给确认得分并结束本单元；达标自动闭环，未达标要写理由；
- **AI 辅助**：选一个角色（提问者 / 答案机 / 出题者 / 挑错者 / 书记员 / 选题），把你的内容发给它；
- **会话记录**：用 AI 辅助发过之后，这里按时间回放每一轮对话（你问了什么、它答了什么）。

**缺口**：列出你**还不太懂的地方**，分「轻微 / 一般 / 严重」三档，方便你优先补。

### 卡片
每当你验证通过一项内容，系统会生成一张**要点卡片**，写清关键结论。卡片是你自己的笔记，日后复习、回顾都靠它。

### 概念图
把学到的知识点画成一张**关系网**：每个圆点是一个「概念」，连线表示它们之间的关系（比如 A 是 B 的「前置知识」）。点圆点看详情，拖动摆放位置，滚轮缩放。

### 知识库
把你自己的资料接进来：填一个**本地文件夹的绝对路径**（支持 .md / .txt），系统只读建索引。之后在「检索」里输入关键词，就能找到原文；检索不到时会明确显示「未检索到」，不会编造内容。再次点「建索引 / 更新索引」只会重建改动过的文件；勾「强制全量重建」可整体重来。

### 分析
用图表看学习进展：花费走势、概念验证时间线、各状态单元的分布。点「7 天 / 30 天…」可切换时间范围。

### 预算
调用 AI 模型会花钱。这里按「学习会话」汇总花费，并对照**月度预算上限**（默认 $10/月，可在设置调整）统计，用颜色提醒你：
- 🟢 **正常**：花费还在预算之内
- 🟡 **临近上限**：花费已到预算的 80%，注意控制
- 🔴 **已超限**：已达到预算上限，需你确认后才放行

红色时需要你点一下「确认继续」。

### 复测
学过的东西隔一段时间容易忘。这里列出**该复习的内容**，点「开始复测」温习一下即可，不用从头再学。

### 周盘点
每周花 15 分钟：这里把「不阻塞但该补」的缺口集中列出来，你一次勾选处理（补完了 / 不补了 / **推迟 7 天**）。如果某个缺口得先补别的东西，就在「前置」里写一句；页面顶部还会给出「下一单元该升难度还是降难度」的建议。

### 账本与撤销
从单元页底部「前往账本总览」进入。这里能看到四本账（缺口 / 单元 / 卡片 / 概念）与四个角度的度量；页面底部「最近操作」列出你对账本的每一次修改，**每条都能撤销**——撤销会把那次修改回滚，并把「撤销」本身也记一笔。

### 设置
这里调「考试多少分算及格」之类的标准，系统已给好默认值，**一般不用改**。每个项目后面的「?」悬停能看通俗解释。留空 = 不改这项。

### 错误提示 · 技术细节
出错时界面**先把结论说人话**，原文藏在可展开的「技术细节」里，不需要懂技术也能知道下一步：

```
deepseek 返回 401：密钥无效或已失效，请到「设置 → 密钥」重新填写（A040001）
▸ 技术细节
```

- 括号里的 `A040001` 一类是**错误码**，报问题时把它一起说上，维护者能立刻定位。
- 只有想知道细节时才点开「技术细节」；里面是模型服务商的英文原文，通常不用看。
- 常见结论：`401` 密钥无效、`403` 没有权限、`404` 模型名或地址不对、`413` 内容太大（缩短输入或减少资料挂载）、`422` 参数不被接受。
- 预算超限会显示 `A080001`，按提示到「预算」点确认即可；没选项目时的提示是 `A010001`，先去顶栏切一个项目。

### 备份
点「导出当前库快照」，把全部学习数据存成一份存档。建议**定期备份**，换电脑也不怕丢。

### 导出
把当前项目的学习数据整理成一份 Markdown 文档，方便你保存、打印或分享给别人。

## 四、界面名词对照表

界面上有些词你可能没见过，这里对照成日常说法：

| 界面上的词 | 意思（大白话） |
|------------|----------------|
| 未开始 / INIT | 刚建立，还没开始动手 |
| 选题中 / PICK | 正在挑要攻克的知识点 |
| 学习中 / LEARN | 正在阅读、理解相关内容 |
| 产出中 / PRODUCE | 正在动手写出或做出点东西 |
| 验证中 / VERIFY | 正在检查自己的产出对不对 |
| 评判中 / JUDGE | 判断自己到底掌握没有 |
| 整合中 / INTEGRATE | 把新学的并入整体知识 |
| 已完成 / CLOSED | 这个学习单元已经结束 |
| 缺口 | 你还没弄懂、需要补的地方 |
| 卡片 | 验证通过后生成的要点笔记 |
| 概念图 | 知识点之间的关系网 |
| 复测 | 隔段时间回来巩固复习 |
| 预算 / 花费 | 调用 AI 模型产生的费用 |
| 正常 / 临近上限 / 已超限 | 花费在预算内 / 快到顶了 / 已超，需确认 |

## 五、常见问题

**点「向导」提示还没选项目？**
先完成第 1 步「创建项目」，向导会自动切换到它。也可以回首页点「新建项目」。

**测试连接失败？**
多半是密钥填错，或网络不通。重新检查第 2 步的密钥，确认没多复制空格；仍不行就问给你模型账号的人。

**花费变红了怎么办？**
那是提醒你快超预算了。页面会弹窗请你「确认继续」，想继续就点确认；想省着用就在「设置」里调整预算上限。

**数据会丢吗？**
去「备份」点一下导出快照，数据就存下来了。建议定期备份。

**还有看不懂的地方？**
回到页面，把鼠标悬停在带「?」的词上，会弹出通俗解释；或随时点导航栏「帮助」看本手册。
