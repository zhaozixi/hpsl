## 3. 本轮发现并修复的真实缺陷

| 缺陷 | 现象 | 修复 |
|---|---|---|
| `httpx.stream` 缺少 method | 真实流式报 `stream() missing 1 required positional argument: 'url'` | 调用改为 `self._stream("POST", url, ...)`，并加适配器层单测断言 `args[0]=="POST"` |

> 与前两轮同因：fake adapter 绕过了默认 HTTP 路径。`scripts/live_check.py --stream` 现可覆盖此链路。

## 4. 决策与偏差

| 编号 | 决策 | 说明 |
|---|---|---|
| D-M29-1 | DeepSeek 价格按**高峰价**换算，汇率 7.2 写死并注明 | 宁高估预算；汇率变动由用户改 `pricing.yaml` |

| D-M29-3 | 判定组只拆 5 个端点 | `restatement`/`boundary-answer`/`followup` 语义与 `/attempts`（kind）重合，重复端点只会增加维护面；已在文档标注 |
| D-M29-4 | 流式仅 OpenAI 兼容协议；Anthropic 降级为一次性推送 | v0 主力是 OpenAI 兼容（8 家厂商中 7 家）；Anthropic 真流式可后续补 |
| D-M29-5 | 恢复只允许 `backups/` 内文件 + 留底 + 双次 integrity_check | 防止误用任意文件覆盖库 |
| D-M29-6 | 每日快照按 UTC 日期判重 | 与 `ts` 口径一致；跨时区用户以 UTC 为准 |
