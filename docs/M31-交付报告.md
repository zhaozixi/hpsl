## 2. `.venv` 修复记录（失败）

| 尝试 | 结果 |
|---|---|
| 修改 `pyvenv.cfg` 的 `home` 指向 vendor python | 仍 103：`did not find executable at ...` |
| `vendor python -m venv .venv2`（含 ensurepip） | ensurepip 子进程 103 |
| `vendor python -m venv --copies --without-pip .venv3` | 创建成功，但 venv 内 python 启动仍 103 |
| 结论 | 当前 WorkBuddy vendor python 无法作为 venv base（疑似启动器限制）；**回滚全部改动**，删除 `.venv2/.venv3` |

工作方式维持：`PYTHONPATH=.venv/Lib/site-packages` + `D:\soft\WorkBuddy\resources\vendor\python\python.exe`。README 已注明。
