## 0. 背景与目标

HPSL 是一个本地个人学习管家工具。其界面沿用了工程化命名（如单元状态 `INIT / PICK / LEARN …`、
花费状态 `ok / warn / blocked`、概念关系 `prereq / relate …`、度量项「通过率 / 校准偏差 / 孤岛节点占比」等），
对**无编程基础、使用过 workbuddy 等工具但不懂学术名词**的普通用户存在较高认知门槛。

本里程碑目标：在不改动任何后端逻辑、不触碰数据库（零 DDL）的前提下，**仅改造视图层（templates/ + static/），
把界面改得让非技术用户能顺畅理解并独立使用**。

---

## 1. 用户原始诉求（摘录）

> 请优化该网站的易用性，使其适配无编程基础、使用过 workbuddy 等工具、难以理解学术名词的终端普通用户。具体要求：
> 1. 为网站各功能模块补充通俗的用户说明文字，避免专业术语；
> 2. 将界面中的学术术语替换为日常易懂表述，或增加悬浮提示、脚注等通俗解释；
> 3. 降低整体认知门槛，确保非技术用户能顺畅理解并独立使用各项功能；
> 4. 以人机交互体验师视角，借鉴成熟产品的设计范式，重新梳理并优化网站界面布局、导航结构与交互流程，提升操作直观性。
> 另外给出一份网站操作手册。状态：INIT 这种改成中文显示。

## 2. 范围

### 2.1 做（In Scope）

| 维度 | 内容 |
|------|------|
| 模块说明 | 每个页面顶部新增「通俗说明横幅」，一句大白话讲清「这是干嘛的、怎么用」 |
| 术语翻译（状态） | 单元状态 `INIT→未开始`、`PICK→选题中`、`LEARN→学习中`、`PRODUCE→产出中`、`VERIFY→验证中`、`JUDGE→评判中`、`INTEGRATE→整合中`、`CLOSED→已完成` |
| 术语翻译（花费） | `ok→正常`、`warn→临近上限`、`blocked→已超限` |
| 术语翻译（缺口级别） | `1→轻微`、`2→一般`、`3→严重` |
| 术语翻译（概念关系） | `prereq→前置知识`、`relate→相关`、`example→示例`、`cause→因果`、`part→组成部分`、`refine→细化`、`supersede→更新替代` |
| 行内术语提示 | 对「通过率 / 校准偏差 / 孤岛节点占比」等学术词加「?」悬浮气泡，悬停看大白话 |
| 字段中文标签 | 单元详情的数据库字段名换成中文标签（标题 / 状态 / 难度档 / 降级次数 …） |
| 导航与品牌 | 导航按「学习 / 查看 / 系统」分组；品牌「HPSL」→「HPSL 学习管家」；新增「帮助」入口；页脚改为通俗标语 |
| 操作手册 | 交付一份面向非技术用户的中文操作手册（docs + 应用内 `/static/help.html`） |

### 2.2 不做（Out of Scope / 硬约束）

- **零 DDL**：后端枚举值（`UnitState` = `INIT/PICK/…`）、数据库 `status` 列、`cost.status` 等**一律保持不变**；
  仅通过**视图层共享宏**做「显示翻译」，后端无需改动。
- **不碰 `.py` 后端逻辑**：引擎 `engine/` headless 不变；`app.py` 中间件顺序（Security 在内、TraceId 在外）不变；
  不新增/修改任何后端路由（帮助页以**静态文件** `/static/help.html` 提供，免改路由）。
- **不改 `hx-*` 属性与元素 id**：保留所有 HTMX 局部刷新锚点与表单字段名（隐藏域 `name=cur/expected_version` 仍传原始 `unit.status`）。
- **不改 JS 业务逻辑**：`graph.html` 内的 `<script>`（SVG 交互）原样保留，仅翻译其中 HTML 模板里的 `{{ e.kind }}`。

## 3. 设计原则（人机交互体验师视角）

1. **显示翻译而非数据翻译**：术语在「展示层」翻译，数据层零改动 → 守住零 DDL 与后端纪律。
2. **渐进式披露**：页面顶部一句话总览（help_banner）+ 行内「?」按需展开（tip），避免信息过载。
3. **状态可视化**：用**彩色徽标**代替裸英文单词，颜色语义统一（绿=正常/已完成、黄=临近/一般、红=超限/严重）。
4. **导航分组**：把平铺链接按「学习 / 查看 / 系统」分组，降低查找成本（借鉴主流后台「分区导航」范式）。
5. **一致性**：所有状态翻译集中在 `macros.html` 一处维护，避免散落、漂移。

## 5. 风险与对策

| 风险 | 对策 |
|------|------|
| 宏翻译与后端枚举值不一致（如后端改枚举） | 宏集中维护；未知值「原样显示」兜底，不丢信息 |
| 隐藏域误翻导致状态机误判 | 表单隐藏域 `value="{{ unit.status }}"` 保留原始值，仅可见文本翻译 |
| 静态帮助页与主题不一致 | 帮助页复用 `app.css` 与主题脚本，与站点视觉统一 |
| tooltip 在 HTMX 局部刷新后失效 | `app.js` 在 `htmx:afterSwap` 后重新绑定 `[data-tip]` |
