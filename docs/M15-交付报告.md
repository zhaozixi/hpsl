## 1. 实现要点

- **`hpsl/routes/graph.py`**：
  - `load_graph_layout` / `save_graph_layout`：读写 `<project>/graph_layout.json`（写时 `.tmp`→`replace` 原子替换；损坏/缺失返回 `{}`）。
  - `graph_page`：环形默认坐标后用已存布局覆盖节点 x/y。
  - `POST /api/v1/graph/layout`（write_security）：`{layout:{id:{x,y}}}`，仅保留「存在于 concept 表且为数值坐标」的条目，其余忽略；返回 `{"saved": N}`。复用既有守卫，不新增错误码。
- **`hpsl/templates/graph.html`**：节点 `pointerdown`（鼠标）`stopPropagation` 进入拖拽态，按 viewport 变换反算 svg 坐标实时更新 `cx/cy`；`pointerup` 经 `fetch`（带 `X-CSRF-Token`）持久化；触摸端不进入节点拖拽（交 pinch/pan）。
