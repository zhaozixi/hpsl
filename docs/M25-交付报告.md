## 2. 关键决策

| 编号 | 决策 | 理由 |
|---|---|---|
| D-M25-1 | 口令**只**从环境变量读取，缺失即 fail-fast | 符合"口令不落盘"；不做确定性派生（旧实现等于把密钥写在源码里） |
| D-M25-2 | 每文件随机 salt，存于文件头 `HPSL2` | 同一口令在不同文件产生不同密钥；salt 无需保密 |
| D-M25-3 | 旧格式（固定盐、无头）保留只读兼容 | 升级不丢已存密钥；写入即升级 |
| D-M25-4 | `PlaintextCipher` 仅允许显式注入 | 测试与自定义后端仍可用；默认链路绝不选中 |
| D-M25-5 | Host 拒绝改为 403/C403001，`C400003` 保留注册 | 与安全设计 T-01 一致；保留旧码避免破坏历史客户端解析 |
| D-M25-6 | `llm_freq` 用 60s 窗口，其余维度 1s | 文档口径是"10 次/分/会话"，窗口必须按维度区分 |
| D-M25-7 | `sse_concurrency` 先落为并发闸（`hold_sse_slot`），不强造 SSE 端点 | 维度必须有真实实现，但不虚构功能；SSE 端点出现时 `Depends(hold_sse_slot)` 即可 |
| D-M25-8 | `/settings/keys` 的 `locked` 放顶层，不下沉到每个 provider | 现有测试断言 provider dict 恰为 4 字段；顶层扩展不破坏契约 |

## 4. 迁移注意（重要）

- 升级后**必须**设置 `HPSL_MASTER_PASSPHRASE`（Windows 无 keyring 时），否则保存/读取密钥会返回
  A040003 与操作提示。
- 口令丢失 = 已存密钥不可恢复（需重填 API key）。
- 旧密钥文件仍可读，首次写入自动升级为新格式。
