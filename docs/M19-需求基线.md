## 一、范围

M19 = **时间序列区间选择**：在 M17 已落地的「花费趋势（近 30 天）」时间序列基础上，支持用户切换聚合窗口（**7 / 30 / 90 / 180 天**）。区间仅限白名单，越界或非整数输入一律回退默认 30 天（防任意区间注入）。

范围边界（硬）：仅改 `hpsl/routes/stats.py`（compute_stats 签名 + 解析辅助）、`hpsl/templates/stats.html`（动态标题 + 区间链接 + 高亮）、`hpsl/static/app.css`（.range-links 样式）。**不新增端点、不改 16 库对象、不改引擎、app.py 中间件顺序不动**。

---

## 二、实现要点

1. **白名单与解析**（stats.py）：新增 `_ALLOWED_RANGES = (7, 30, 90, 180)` 与 `_parse_range(s)`，非整数或越界一律回退 30。
2. **`compute_stats(pid, days=30)`**：时间序列日期序列改为按 `days` 动态生成（`range(days-1, -1, -1)`），其余聚合（cost_max / unit_breakdown）不变。
3. **路由透传**：`stats_page(req)` / `stats_api(req)` 读取 `?days=` 查询参数，经 `_parse_range` 后传入 `compute_stats`；页面 context 附带 `days` 供模板高亮。
4. **页面**：标题 `花费趋势（近 {{ days }} 天）`；区间链接 `<a href="/stats?days=N">` 对应当前 `days` 加 `.active` 高亮；无记录文案同步 `days`。
