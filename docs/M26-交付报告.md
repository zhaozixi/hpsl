## 2. 关键决策

| 编号 | 决策 | 理由 |
|---|---|---|
| D-M26-1 | 在 `db.write` 内按表名放行缺省 id（仅 `turn`），而不是发明第二个写入口 | 保持"唯一写入口 + 同事务审计"；`turn` 是唯一 INTEGER PK 业务表 |
| D-M26-2 | `append_turn` 只做便利封装，仍调用 `write` | 审计、busy 重试、白名单全部复用，不重复实现 |
| D-M26-3 | 角色调用写两行而不是一行 | 回放需要看到"我问了什么"，否则只剩模型输出无法判断上下文 |
| D-M26-4 | 轮次读取按 `unit_id` 走 `session` join | 与"复测不写当前单元"的隔离语义一致：对话归属会话，会话归属单元 |
| D-M26-5 | 详情页 `LIMIT 100`，不做分页 | v0 单用户，长对话暂不构成问题；分页留后续 |
