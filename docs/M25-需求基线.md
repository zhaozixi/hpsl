## 1. 背景

REF-2 审计发现实现与《安全设计》在四处系统性偏离：密钥可静默降级明文、限流只落三维、Host/Origin 用前缀放行、`/docs` 默认开放。主理人选择 **A：改代码对齐文档**，而非把取舍写进文档。

---

## 2. 范围（In-Scope）

| # | 项 | 目标行为 |
|---|---|---|
| P0-05 | 密钥 | 口令（`HPSL_MASTER_PASSPHRASE`）+ 每文件随机 16B salt + Argon2id（64MiB/3/4）；无口令或 cryptography → **fail-fast（A040003）**，不再明文降级 |
| P0-06 | 限流 | 五维齐全：`llm_freq`（10 次/60s/会话）落地到角色调用；`sse_concurrency` 提供并发闸（SSE 预留） |
| P0-07 | Host/Origin | Host 精确匹配（含端口，空白名单全拒）；Origin 精确匹配（scheme+host+port）；拒绝码统一 403/C403001 |
| P0-08 | 文档端点 | 关闭 `/docs`、`/redoc`、`/openapi.json`（404） |

**Out-of-Scope**

- 启动时交互式输入口令（当前只读环境变量；交互式留后续）；
- keyring 实测（环境未安装 keyring，仍保留优先分支）；
- CSRF 签名 cookie（P1-06，双提交仍是当前取舍）；
- SSE 端点本身（只补并发闸，v0 无 SSE）。

## 3. 关键契约变化

| 项 | 变化 | 兼容性 |
|---|---|---|
| `check_host` | `host.startswith("127.")` 与空白名单放行**删除** | 默认 `127.0.0.1:8765` 仍通过（自动补端口） |
| Host 拒绝响应 | 400/C400003 → **403/C403001** | C400003 保留注册，但不再产生（CHG-06） |
| `check_origin` | 只判 hostname → **精确 origin** | 本机同端口页面不受影响 |
| `FileBackend` | 默认要求口令；文件格式 `HPSL2+salt+token` | **旧格式可读**（固定盐 legacy 分支） |
| `set_api_key` | 锁定 → A040003（带操作提示） | 设置页/向导会显示该错误 |
| `GET /settings/keys` | 顶层新增 `locked` / `lock_reason` | `providers[]` 字段保持 4 个不变 |
| `POST /roles/{role}/call` | 增加 `llm_freq` 检查 | 默认 10 次/分/会话；超限 C429001 |
| `FastAPI(...)` | `docs_url/redoc_url/openapi_url = None` | 无 API 消费方，无影响 |

## 5. 迁移与运维

1. **必须**设置 `HPSL_MASTER_PASSPHRASE`（Windows 无 keyring 时）；建议 ≥12 位、仅存于环境/启动脚本。
2. 已有 `*.fernet`（旧格式）仍可读；首次写入会升级为新格式。
3. 口令丢失 = 已存密钥不可恢复（需重新填写 API key）——这是"口令不落盘"的必然代价。
4. `HPSL_RATE_WINDOWS` 可覆盖维度窗口（测试/调参用），默认 `llm_freq=60`。

---

## 6. 风险

| 风险 | 缓解 |
|---|---|
| 强制口令影响首次体验 | 设置页/向导显示明确原因；后续可加交互式输入 |
| Argon2id 每次读写都要派生（~几十 ms） | 仅密钥读写时发生，不在请求热路径 |
| 关闭 OpenAPI 影响调试 | 本地开发可临时改；文档以 `docs/REF-*` 为准 |
| 精确 Origin 可能拒掉合法但端口不同的本地页面 | 与"只监听单端口"一致，属预期收紧 |
