## 2. 关键契约

- **价格**：`pricing.yaml` 单位为 USD / 1K tokens；DeepSeek 官方价（元/百万 tokens）按 1 USD=7.2 CNY、**高峰价**换算（宁高估不低估），来源与换算写在文件头。
- **未登记价格**：`cost=0` 不静默——`unpriced_models()` 列出，`/cost/monthly` 返回该数组，`/budget` 页显示黄色提示。
- **评分要点**：`GET /units/{uid}/attempts/{aid}/rubric` 仅在 `self_score` 非空时返回，否则 `A050001`（`rubric_reveal_allowed`）。
- **强行闭环**：理由必填（`A050003`），成功后 `forced_close=1` 且不计进度。
- **流式**：SSE 事件 `{"delta": ...}` … `{"done": true, tokens_in, tokens_out, cost_usd}`；失败 `{"error": {code,msg}}`；不支持流式的适配器自动降级为"一次性推送"。
- **恢复**：只接受项目 `backups/` 内的文件；恢复前留底 `pre-restore-*.db`；恢复后 `integrity_check` 失败 → `B999001`。
- **导出**：`conversations` 只读 `session`/`turn`，内容经既有 `_scrub()`。
