## 2. 范围边界

### 2.1 In-Scope（M5 必须交付）

1. **挑错触发四规则（F7.1）`engine/claim_check.py`**
   - `TriggerRule` 枚举（KEYPOINT / CODE_NUM_REF / ANSWER_DISAGREEMENT / MANUAL）。
   - `evaluate_triggers(*, is_keypoint, has_code_num_ref, manual, answer_disagreement=False)`：返回命中规则列表；规则 ③ 在 v0 恒 false（`_ENABLE_ANSWER_DISAGREEMENT_V0=False`，预留参数待 v1 启用）。
   - `should_trigger_critic(...)`：满足任一即触发。
2. **同源降级与异构判定（F7.2 / BD-03）`engine/claim_check.py` + `engine/grading.py`**
   - `same_source(critic_model_id, answer_model_id)`：复用 `heterogeneous`，相交 → 同源 True。
   - `record_same_source_warning(pid, *, unit_id, critic_model_id, answer_model_id, is_keypoint, ...)`：写 `claim_check` 同源警告行（agree=NULL，providers 含 same_source/keypoint 标记）。
   - `grading.evaluate_close` 新增 `is_keypoint` / `same_source` / `explicit_confirm` 参数：关键卡点且同源 → `close_allowed=False, same_source_keypoint_block=True`；`explicit_confirm=True` 方可闭环并留痕。
   - `grading.close_unit` 同步接入；同源关键卡点经显式确认闭环时标记警告行为「同源显式确认」（`mark_same_source_confirmed`）。
3. **用户仲裁 `arbitrate(pid, *, claim_id, ruling)`（F7.1）**
   - `user_ruling ∈ {采纳, 驳回, 待验证}`：采纳 → residual=1（阻断）；驳回 → residual=0（不阻断）；待验证 → residual=1 但**不阻断**闭环（仅入质量度量，§5.5 AC-5.2/5.4）。
   - 非法裁决 → `C400001`。
4. **claim_check 落账（零 DDL）**：`write_claim_check(...)` / `trigger_critic_if_needed(...)` 经 `db.write` 同事务审计；表已 M0 锁定，仅 INSERT/SELECT。
5. **A050001 守卫 `engine/grading.py`**
   - `rubric_reveal_allowed(*, answered, self_scored)`：产出且自评后才可揭示。
   - `filter_judgment_data(data, *, answered, self_scored)`：未达成前剔除 `rubric` 键，确保评分要点不提前流向界面（AC-3.7）。
6. **治理计数（AC-5.4）`count_same_source_keypoint_auto_close(pid)`**：同源关键卡点「自动闭环」违规次数，引擎保证恒为 0（区分合规的显式确认闭环）。
7. **测试**：`tests/test_claim_check.py`（23 例，覆盖 F7.1/7.2/BD-03/A050001/仲裁/治理计数）。
8. **回归**：M0–M4 既有 **112** 测试仍全绿（AC-M5-8）。

### 2.2 Out-of-Scope（M5 不做，留待后续）

## 4. 接口契约（AC-M5 对应基线验收）

| 接口 | 语义 | 对应 AC |
|------|------|---------|
| `evaluate_triggers(...) -> list[TriggerRule]` | 四规则命中判定；规则 ③ v0 恒 false | F7.1 / AC-5.1（触发面） |
| `same_source(critic, answer) -> bool` | 复用 heterogeneous：同厂商/谱系相交/蒸馏 → True | F7.2 / AC-5.1 |
| `record_same_source_warning(...)` | 写同源警告（agree=NULL） | F7.2 / AC-5.1（界面警告数据源） |
| `evaluate_close(..., is_keypoint, same_source, explicit_confirm)` | 同源关键卡点拒绝自动闭环 | BD-03 / AC-5.2 |
| `close_unit(..., explicit_confirm=True)` | 同源关键卡点显式确认闭环 + 留痕 | BD-03 / AC-5.2 |
| `arbitrate(..., ruling)` | 采纳/驳回/待验证；待验证不阻断 | F7.1 / AC-5.2 |
| `count_same_source_keypoint_auto_close(pid)` | 违规自动闭环计数恒 0 | AC-5.4 |
| `rubric_reveal_allowed` / `filter_judgment_data` | 评分要点作答前不可见 | A050001 / AC-3.7 / AC-5.3 |
