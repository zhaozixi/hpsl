## 4. 注意与取舍

1. **千问端点已切换**为 MaaS 地址：原有 `qwen-plus` / `qwen-max` 也会走该端点；若该端点不提供旧模型，需改回 DashScope 或为旧模型单独加 provider。
2. **图片仅支持 URL 或 data URI**：本地文件请用 `--image-file`（脚本会自动 base64）或自行传 data URI；接口层不做文件上传。
3. **思考模式**：智谱默认思考会消耗输出 token（同样 `max_tokens` 下可能正文为空）；HPSL 不设 `max_tokens`，不影响使用。
4. **密钥安全**：两把 key 均已在会话中出现，**请轮换**；仓库无明文 key（脚本只读 `HPSL_LIVE_KEY`/`DEEPSEEK_API_KEY`，临时 `HPSL_HOME` 用完即删）。
