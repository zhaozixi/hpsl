## 1. 模块定位（§3.2.M9.1）

`治理度量` 覆盖**计数型指标计算、四平面度量、软提示 / 熔断信号**，是 BC-7 支撑域（L3 治理层规则层实现）。

- 业务逻辑在系统内部由账本**读时重算**，向**学习者（治理态）**输出软提示。
- 涉及 **M7 四本账与审计**（只读）、**M2 流程状态机**（熔断处置入口）、**M10 Web 接入**（账本总览四平面视图）。
- 纪律：**指标是可重算的视图，不是账本；LLM 只提建议、不打分、不裁决**。

## 3. CountsVO（§3.2.M9.3，12 字段四平面；规格 prose 误写「13」，以本 DTO 为准）

| 平面 | 字段 | 口径 |
| --- | --- | --- |
| 质量 | `pass_rate` | 重述 + 边界题通过率（强行闭环单元剔除；复测权重 2 > 当场作答权重 1；confirmed_score ≥ pass_threshold 记为通过） |
| 质量 | `review_pass_rate` | 仅 `attempt.kind=复测` 的通过率 |
| 质量 | `calibration_gap` | `mean(self_score − confirmed_score)`；正 = 高估自己 |
| 节奏 | `l1_gap_sessions` | 一级缺口（level=1）数量 > `l1_gap_limit`（默认 5）的会话数 |
| 节奏 | `zero_gap_ratio` | 零缺口会话占比；**分母只算 `gaps_confirmed=1` 会话**，分子 = 其归属单元零缺口 |
| 进度 | `unit_completion` | 已闭环且非强行闭环单元 / 总单元 |
| 进度 | `gap_clear_ratio` | （已补 + 已验证）/ 总缺口 |
| 进度 | `l2_gap_backlog` | level=2 且 status=待补 的积压量 |
| 风险 | `forced_close_ratio` | 强行闭环单元 / 总单元（上限 0.10） |
| 风险 | `skipped_produce_ratio` | 跳过产出单元 / 总单元（上限 0） |
| 风险 | `unresolved_disagreements` | 未裁决实质分歧数（claim_check：真实挑错且 `user_ruling IS NULL`，**排除同源降级告警**） |
| 风险 | `isolated_node_ratio` | 无出入边（concept_edge.src/dst）的概念节点占比 |

**样本不足降级**：分母为 0 的指标返回 `0.0`（「数据积累中」由 M10 展示层标注）；本里程碑不触发升降建议（suggest_band 留 v1）。

## 4. 关键流程逻辑（§3.2.M9.5）

### Step 1 · 口径计算（确定性，不用 LLM）
- `pass_rate`：强行闭环单元不计入（污染升降判断）；复测权重高于当场作答。
- `calibration_gap`：`mean(self_score − confirmed_score)`；正 = 高估。
- `zero_gap_ratio`：分母只算 `gaps_confirmed=1` 会话（防「从不确认缺口」操纵）。
- `isolated_node_ratio` / `unresolved_disagreements`：分别来自 `concept_edge` 与 `claim_check`。

### Step 2 · 四平面阈值比对（优先级 风险 > 质量 > 节奏 > 进度）
- **风险**：未裁决分歧 / 强行闭环占比超 0.10 / 跳过产出占比超 0 / 孤岛节点占比（>0 即提示，>0.2 升 warn）。
- **质量**：通过率 > 0.80（偏高）或 < 0.60（偏低，目标区间 60%~80%）；校准差距 ≥ 0.2 提示高估/低估。
- **节奏**：一级缺口超上限会话数 > 0；零缺口占比 > 0.20。
- **进度**：二级缺口积压 > 0 且清账率 < 0.5。

### Step 3 · 输出
- 软提示：日常语言、可一键处理（继续 / 补前置 / 降级）、**可关闭（`dismissible=True`）**、每会话提示数有上限（`max_prompts`，默认 8）。
- 样本不足守卫（`ctx` 基数）：避免「无数据却误报偏低」（如 `attempts=0` 时不报「通过率偏低」）。

## 5. 纪律守住（M0 冻结约束）

- **零 DDL**：全部只读 `SELECT`，不新增/改动任何表或列；实测 `count_user_objects == 16`。
- **`write` 唯一写入口**：本模块无任何写入（纯派生视图）。
- **headless**：`governance.py` 不依赖 `routes` / `app`（经 `test_headless_no_forbidden_imports` 扫描引擎包，无 `routes`/`app`/`fastapi` 导入）。
- **错误码分段**：M9 无新码空间；缺失项目回退失败用 `ValueError`（编程错误，非业务码）。
- **隔离红线（O13）/ 密钥红线（D1 §6.5）**：不涉及。
