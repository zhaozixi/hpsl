## 2. 范围与边界

### 2.1 In-Scope 已交付
1. **候选缺口批量确认 `confirm_gap_candidates(pid, items, actor='user')`**：confirm → 写 gap（status=待补）+ 候选置「已确认」；discard → 候选置「废弃」；幂等（已确认/已废弃/缺失跳过）；非法 action/等级 → C400001；返回计数。
2. **缺口账本查询 `list_gaps(pid, ...)`**：按 unit_id/level/status 过滤，返回 `list[GapListVO]`。
3. **四本账统计摘要 `ledger_summary(pid) -> dict`**：gaps/units/cards/concept_edges/concepts/reviews_active 计数，不暴露原始对话，供 M2 选题与 M9/M10 复用。
4. **DTO/VO（`common/dto.py`）**：`AuditEntryVO` / `GapConfirmRequest` / `UndoRequest` / `CardCreateRequest` / `GapListVO`。
5. **导出补齐**：`engine/__init__.py` 导出 `confirm_gap_candidates` / `list_gaps` / `ledger_summary`。
6. **测试**：`tests/test_ledger.py`（10 例）。

### 2.2 Out-of-Scope（留待后续，未做）
- HTTP 路由（/api/v1/ledger*、/api/v1/gap-candidates/confirm、/api/v1/audit/{aid}/undo、/api/v1/cards、/api/v1/concept-edges）属 M10；卡片建卡/概念图写边的 UI 编排与句式解析属 M10；Markdown 备份导出（AC-7.1）属 M10；四平面阈值面板与周盘点界面属 v1（M7 排期标签）。

## 3. 与锁定基线的偏差与实现决策（须记录）

| # | 偏差/决策 | 原因 | 处理 | 影响 |
|---|-----------|------|------|------|
| D-M7-1 | 确认入账时 `gap.session_id` 置 NULL | 候选缺口不直接携带 session；缺口归单元 | 确认写 gap 时 `session_id=None`；M10 可回填 | 无 DDL；FK 允许 NULL |
| D-M7-2 | 非法 action/等级复用 `C400001` | 基线 M7 错误空间仅 A070001/A070002（M0 已注册） | 参数校验统一 C400001 | 不污染错误码表 |
| D-M7-3 | `gap_candidate.status` 扩展取值「已确认」 | 幂等需标记已消费候选；列自由 TEXT 无约束 | 确认后置 status='已确认' | 零 DDL；纯值约定 |
| D-M7-4 | `write`/`undo` 复用 M0 `db.py`，不复刻 | 基线内部 API 与 M0 db.write/db.undo 一一对应且已含审计+指纹回滚 | M7 仅做编排层 | 严格单一写入口纪律 |
| D-M7-5 | 确认后标记 `session.gaps_confirmed=1`（§3.2.M7.5 Step 3） | 独立验证 Agent 指出该分母口径（M9 零缺口占比）原未在 M7 实现；主理人已补 `_session_ids_for_unit` 并在 confirm/discard 后按 unit 归属会话置 1 | 经 `db.write("session", ...)` 同事务审计；幂等（重复置 1 无害） | 零 DDL；对齐基线流程 |
| D-M7-6 | DTO 形状与基线 §3.2.M7.3 字面不完全一致 | `AuditEntryVO.id`/`UndoRequest.audit_id` 实码为 `int`（匹配 audit_log.id INTEGER 主键）；`GapConfirmRequest` 实码为单条三字段、`ledger` 函数以 `list[dict]` 批量入参（比基线 `items:tuple` 更贴合批量确认）；`GapListVO`/`CardCreateRequest` 已定义供 M10 消费 | 功能不受影响（M7 内部以 dict 运转）；M10 接入时与实码对齐即可 | 已在本文与实现规格登记，属文档漂移非缺陷 |

> 以上偏差均不触及 `db.py` / `routes/` / `app.py` 既有逻辑与 M0 锁定的 16 库对象（零 DDL）。独立验证 Agent 提的 2 项基线符合度事项（DTO 形状、session.gaps_confirmed）已由 D-M7-5/D-M7-6 闭环或登记。
