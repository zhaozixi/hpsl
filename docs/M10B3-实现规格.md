## 1. 第三批范围

### 1.1 单元索引页 `GET /unit`
- 新增 `hpsl/templates/unit_index.html`（extends `base.html`）：列出当前激活项目全部单元（按 created_at 升序）。
- 新增页面路由（`routes/unit.py` 的 `page_router`）：`GET /unit` → `read_security`；无激活 → 渲染「尚未选择项目」。context：`project`、`units`（list[dict]，含 id/title/status/forced_close/closed_at）。
- 每个单元一行：标题、状态、是否强制闭环、链接到 `/unit/{uid}`。

### 1.2 单元详情 + 工作流页 `GET /unit/{uid}`
- 新增 `hpsl/templates/unit_detail.html`（extends `base.html`）：单单元详情。
- `GET /unit/{uid}` → `read_security`。context：`project`、`unit`（dict）、`allowed_next`（list[str]，由当前 status 经 `state.TRANSITIONS` 推算）、`gaps`（ledger.list_gaps(pid, unit_id=uid)）、`claim_checks`（db 查询 claim_check where unit_id=uid，providers JSON 解析后展示）。
- 页面分区：
  1. **单元元信息**：title、status、difficulty_band、degrade_count、production（截断展示）、produced_at、skipped_produce、forced_close、closed_at。
  2. **工作流（M2）**：当前 status + 可用下一状态（`allowed_next`）。每个下一状态一个「推进到 {next}」按钮（htmx POST 到 move 端点，`hx-target` 工作流面板 `hx-swap="outerHTML"`，携带 `cur`/`nxt`/`expected_version` 隐藏域 + 可选 `reason` 输入）。进入 VERIFY 时 `reason` 必填（PRODUCE 闸门）；其他转移 reason 可选。
  3. **缺口（M7）**：本单元缺口列表（level/text/status），来自 `ledger.list_gaps`。
  4. **挑错（M5）**：本单元 claim_check 列表（claim/agree/diff/user_ruling/residual）。每条含仲裁按钮「采纳 / 驳回 / 待验证」（htmx POST 到 arbitrate 端点，`hx-target` 该行 `hx-swap="outerHTML"`）。

### 1.3 REST 端点（消费 M2/M5/M7）
- `GET /api/v1/units`（`read_security`）→ `ok([unit dict...])`；无激活 → A010001。
- `GET /api/v1/units/{uid}`（`read_security`）→ `ok({unit, allowed_next, gaps, claim_checks})`；单元不存在 → A020001。
- `POST /api/v1/units/{uid}/move`（`write_security`）→ 解析 `cur`(str, 必填) / `nxt`(str, 必填) / `reason`(str, 可选) / `expected_version`(str, 可选) → 调 `state.move(pid, uid, cur, nxt, reason=reason, actor="user", expected_version=expected_version)` → `ok(UnitStateVO.to_dict())`。htmx 请求返回工作流面板片段（新 status + allowed_next 按钮）。错误：非法/冲突转移 → A020001；进 VERIFY 且 production 空无 reason → A020003。
- `POST /api/v1/units/{uid}/claim-check/{cid}/arbitrate`（`write_security`）→ 解析 `ruling`(str, ∈ {采纳,驳回,待验证}) → 调 `claim_check.arbitrate(pid, claim_id=cid, ruling=ruling)` → `ok({claim_id, ruling})`。htmx 返回该行更新片段。非法 ruling → C400001（引擎抛出）。

## 2. 引擎 API 契约（实现须严格对齐）

### M2 `engine/state.py`
- `TRANSITIONS: dict[UnitState, tuple[UnitState,...]]`：INIT→(PICK)、PICK→(LEARN)、LEARN→(PRODUCE,VERIFY,PICK)、PRODUCE→(VERIFY,LEARN)、VERIFY→(JUDGE,LEARN)、JUDGE→(INTEGRATE,LEARN)、INTEGRATE→(PICK,CLOSED)、CLOSED→()。
- `move(pid, uid, cur, nxt, *, reason=None, actor="user", expected_version=None) -> UnitStateVO`：
  - 单元不存在 → A020001；`cur` 与库内 status 不符（或 `expected_version` 不符）→ A020001（无写账）；
  - `nxt` 不在 `TRANSITIONS[cur]` → A020001；
  - 进 VERIFY 且 `production` 空：有 `reason` → 置 `skipped_produce=1` 放行；无 `reason` → A020003；
  - 成功经 `db.write` 落账，返回 `UnitStateVO(status, allowed_next)`。
- `UnitStateVO.to_dict()` → `{"status":..., "allowed_next":[...]}`。
- `UnitState`（common/enums.py）：INIT/PICK/LEARN/PRODUCE/VERIFY/JUDGE/INTEGRATE/CLOSED（均为 str 枚举，`.value` 为同名大写串）。
- 路由可用 `state.TRANSITIONS[UnitState(status_str)]` 推算 `allowed_next`（只读，不调用 move）。

### M5 `engine/claim_check.py`
- `arbitrate(pid, *, claim_id, ruling)`：`ruling` 须 ∈ {采纳,驳回,待验证}（否则 C400001）；写 `user_ruling` + `residual`（采纳/待验证→1，驳回→0）经 `db.write`；返回 None。
- `write_claim_check(pid, *, claim, unit_id, providers=None, session_id=None, agree=None, diff=None, user_ruling=None, residual=0, actor="system") -> str`（测试可用以造 claim_check 行）。
- 表 `claim_check` 列：id/claim/providers(JSON 文本)/unit_id/session_id/agree/diff/user_ruling/residual。

### M7 `engine/ledger.py`
- `ledger_summary(pid) -> dict`（四本账摘要，可选展示项目级概览）。
- `list_gaps(pid, unit_id=None, level=None, status=None) -> list[GapListVO]`：按 unit_id 过滤取本单元缺口。GapListVO 字段：id/unit_id/session_id/level/text/status/context/created_at/updated_at。

## 3. 纪律约束（必须守住）

- **零 DDL**：不新增表/列/索引；所有写经 `state.move` / `claim_check.arbitrate` / `claim_check.write_claim_check` → `db.write`（既有表 unit/claim_check）。`routes/unit.py` 不得直写 `db.write`、不得含 CREATE/ALTER。
- **写唯一入口**：仅经 engine 内部 `db.write`；不得直写 `audit_log`/原生 SQL。
- **错误码**：复用既有（A010001 无激活/单元不存在、A020001 状态冲突/非法转移、A020003 跳过产出缺理由、C400001 参数/非法仲裁、C403001 来源不被允许、C429001 限流）；无新码空间。
- **安全**：页面 GET 与 units/detail GET 用 `read_security`；move/arbitrate 用 `write_security`。
- **headless**：engine 层不依赖 routes/app（本批次不改 engine）。
- **复审守护**：`tests/test_governance.py::test_governance_zero_ddl`（==16）与新增 `tests/test_web_m10b3.py::test_zero_ddl_after_unit_features` 必须仍通过。
