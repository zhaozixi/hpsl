## 一、范围

M15 = **概念图节点拖拽 + 坐标持久化**：延续 M13 概念图交互线，支持鼠标拖拽节点，并在下次打开时恢复布局。

**关键决策（D-M15-1）**：为守住项目硬红线（零 DDL / 16 库对象锁 / `db.write` 唯一写入口），坐标**不**落新表或新列，而是存每项目 `graph_layout.json` 文件（与 M10B 备份文件级 I/O 同构，走 os 级写、不触 `db.write`）。如此全程零 DDL、16 库对象不变。

范围边界（硬）：仅改 `hpsl/routes/graph.py`（读/写布局 JSON + 新增 `POST /api/v1/graph/layout` 写端点，复用既有错误码、不新增）、`hpsl/templates/graph.html`（节点拖拽 + 持久化）、新增测试。不触碰 16 库对象、引擎核心、中间件顺序、密钥红线。

## 二、实现要点

1. **`graph.py`**：
   - `load_graph_layout(pid)` / `save_graph_layout(pid, layout)`：读写 `<project>/graph_layout.json`（`{layout: {concept_id: {x,y}}}`），写时先写 `.tmp` 再 `replace` 原子替换；文件缺失/损坏返回 `{}`。
   - `graph_page`：计算环形默认坐标后，用已存布局覆盖节点 x/y。
   - `POST /api/v1/graph/layout`（write_security）：body `{layout:{id:{x,y}}}`；仅保留「存在于 concept 表 + 数值坐标」的条目，其余忽略；落盘返回 `{"saved": N}`。复用既有错误码（缺项目→A010001 经 read/write 守卫；不引入新码）。
2. **`graph.html`**：
   - 节点 `<g class="node">` 绑定 `pointerdown`（鼠标）：`stopPropagation` 阻止视口平移，进入拖拽态，按当前 viewport 变换反算 svg 坐标更新节点 `cx/cy` 与文本位置。
   - `pointerup`：退出拖拽态并 `fetch POST /api/v1/graph/layout`（带 `X-CSRF-Token`）持久化；失败静默。
   - 触摸端不进入节点拖拽（交给既有 pinch/pan），避免冲突。
