## 1. 批次1：备份自动轮转调度增强

### 实现要点
- **`db.rotate_all_backups(keep_daily=7, keep_monthly=12)`**：遍历 `projects.list_projects()`，对每个项目调用既有 `rotate_backups(pid)`（仅删外部 `project-*.db`，前缀/正则双重保护）。零 DDL、best-effort（缺失 backups 目录跳过、单项目异常不影响其余）。
- **`serve()` 启动即轮转**：在 `server.run()` 前调用 `db.rotate_all_backups()`，实现「启动即清理过期快照」的无人值守起点。
- **周期定时轮转**：`serve()` 启动一个 daemon 线程，每 `HPSL_ROTATE_INTERVAL_SECONDS`（默认 21600 = 6h，env 可配）调用一次 `db.rotate_all_backups()`；经 `atexit` 停止。整段 try/except 包裹，失败仅记日志不影响主服务。
- **CLI 子命令**（`app.main` argparse）：
  - `hpsl rotate [--pid PID]`：立即轮转全部项目（或指定 pid），打印各项目删除数。
  - `hpsl backup [--pid PID]`：对全部（或指定）项目执行 `db.backup_project(pid)`（其内部已轮转），打印生成路径，便于外部 cron 调度。
  - `serve` 行为不变。

### 改动文件
- `hpsl/db.py` — 新增 `rotate_all_backups()`（在 `rotate_backups` 之后）。
- `hpsl/app.py` — `serve()` 增加启动即轮转 + daemon 周期线程（env 间隔、atexit 停止）；`main()` 增加 `rotate` / `backup` 子命令（经 `db.rotate_backups` / `db.rotate_all_backups` / `db.backup_project` + `projects.list_projects`，单项目失败不中断）。
- `tests/test_m13_backup.py`（新增 3 例）：跨项目保留逻辑、CLI `rotate`、`backup` 输出。

## 2. 批次2：概念图交互再打磨

### 实现要点
- **`graph.py`**：节点 dict 增补 `verify_status`（读 `concept.verify_status`，只读查询，零 DDL），供前端着色与详情面板使用。端点签名/数量不变（仍仅 `/graph` 页面 + 三个 REST）。
- **`graph.html` 交互增强**（纯前端，保留 `selectNode`/`resetView`）：
  1. **缩放控件**：`＋` / `−` / `重置` / `适配`（fit-to-screen）按钮（替代仅滚轮，移动端/键盘友好）。
  2. **悬停提示**：hover 节点显示概念名 + 验证状态 + 最近验证时间（自定义 tooltip）。
  3. **搜索/筛选框**：输入名称高亮匹配节点（`.search-hit` 蓝环）、淡化其余；回车聚焦首个匹配并选中。
  4. **状态着色**：节点圆点按 `verify_status` 着色（已验证=绿 `#0a7d2c` / 未验证=灰 `#9ca3af` / 待验证=琥珀 `#f59e0b`），图例三态齐备。
  5. **高亮过渡**：节点/边 `opacity`/`stroke`/`fill` 加 CSS 过渡，交互更顺滑。
  6. **触控增强**：双指 pinch 缩放 + 中点平移、双击重置；单指平移仍走既有 pointer 路径（2 指时禁用 pointer 拖拽避免冲突）。
- 保留既有 SVG 内联色值（图形渲染必要：`#888` 连线、`#2b6cb0` 等由 JS 按状态覆盖）。

### 改动文件
- `hpsl/routes/graph.py` — 节点 dict 补 `verify_status`。
- `hpsl/templates/graph.html` — 重写交互（缩放控件/悬停/搜索/状态着色/过渡/触控）。
- `tests/test_m13_graph.py`（新增 5 例）：缩放控件+搜索框、data-status 注入、三态图例、既有契约不变、零 DDL。

## 6. 偏差与决策

- **D-M13-1**：周期轮转用 daemon 线程 + `atexit` 停止（本地单用户工具现实可行的"调度"），不引入 OS 级 cron 守护进程。

- **D-M13-3**：概念图状态着色复用既有 `verify_status` 字段，不新增字段/表。
