## 1. 实现要点

### 1.1 共享翻译宏（核心，仅视图层）
新增 `hpsl/templates/macros.html`，集中 7 个宏，后端枚举值**零改动**：
- `state_badge(s)`：`INIT→未开始` … `CLOSED→已完成`，带 `title` 悬浮说明 + 彩色徽标（class `state-*`）。
- `gap_badge(level)`：`1→轻微 / 2→一般 / 3→严重`，class `gap-l*`。
- `cost_badge(s)`：`ok→正常 / warn→临近上限 / blocked→已超限`，class `cost-*`。
- `relation_label(k)`：`prereq→前置知识` 等 7 类关系；**未知值原样显示**兜底。
- `help_banner(title, body)`：页面顶部通俗说明横幅（蓝条 + 💡）。
- `tip(text, explain)`：行内术语「?」角标，悬停看大白话。
- `field(label, value, explain)`：数据库字段名 → 中文标签字段行。

### 1.2 全量模板改造（14 个页面）
每个页面：`{% from "macros.html" import … %}` + `help_banner`（顶部说明） + 状态/术语翻译：
- **单元类**：`unit_index`（状态徽标）、`unit_detail`（状态徽标 + `field` 中文标签 + 缺口 `gap_badge`）、`_unit_wf_panel`（状态徽标；隐藏域保留原始 `unit.status`）、`cards`、`review`。
- **度量/账本类**：`budget`（`cost_badge`）、`_quota_modal`（`cost_badge`）、`ledger`（四本账/四平面度量 + `tip` 解释「校准偏差/孤岛节点占比/强行闭环占比」等）、`stats`（单元状态分布用 `state_badge`）。
- **配置/数据类**：`settings`（每个阈值字段用 `tip` 通俗解释，如「通过阈值=及格线」）、`project_detail`、`create`、`export`、`backup`、`wizard`、`index`、`graph`（`{{ e.kind }}`→`relation_label`，`<script>` 原样保留）。

### 1.3 静态资源
- `hpsl/static/app.css`：新增 M23 区块——`.help-banner` / `.tip`+`.tip-pop` / `.badge.state-*` / `.badge.cost-*` / `.badge.gap-l*` / `.field-list` / `.nav-group-label`+`.nav-sep`（含移动端隐藏）。
- `hpsl/static/app.js`：新增 tooltip IIFE——`ensurePop()` 创建气泡，`show/hide` 绑定 `[data-tip]` 的 mouse/focus 事件；`bind()` 在 `DOMContentLoaded` 与 **`htmx:afterSwap`**（含 `readyState` 兜底）后重绑，保证 HTMX 局部刷新内容也有提示。
- `hpsl/templates/base.html`：导航按「学习/查看/系统」分组（`.nav-group-label`+`.nav-sep`）；品牌「HPSL」→「HPSL 学习管家」（带 title）；各链接加 `title` 通俗解释；新增「帮助」入口（指向 `/static/help.html`）；页脚改为通俗标语。

### 1.4 应用内帮助页（零后端改动）
- 新增 `hpsl/static/help.html`：完整中文操作手册（这是什么 / 四步向导 / 各模块怎么用 / 名词对照表 / 常见问题），复用 `app.css` 与主题脚本，视觉与站点统一。
- 导航「帮助」链接指向 `/static/help.html`（静态文件由既有 `StaticFiles` 挂载，无需新增路由）。

### 1.5 操作手册交付物
- `docs/M23-操作手册.md`：面向非技术用户的完整手册（与站内 `/static/help.html` 内容一致）。

## 3. 纪律守住（硬）

- **零 DDL**：后端枚举 `UnitState`/`cost.status`/`gap.status`/`verify_status`/`edge.kind` 全部不变；
  翻译仅发生在模板层宏，未触 `project.db`，未增库对象（`count_user_objects` 守护仍 16）。
- **不碰 `.py` 后端逻辑**：引擎 `engine/` headless 不变；路由 `routes/*.py` 未改（帮助页走既有静态挂载）；
  `app.py` 中间件顺序（Security 在内、TraceId 在外）不变。
- **`hx-*` / id / 隐藏域不变**：工作流转移表单的 `name=cur/expected_version` 仍传原始 `unit.status`，状态机判定不受影响。
- **JS 业务逻辑不变**：`graph.html` 的 `<script>`（SVG 交互）逐字保留，仅翻译 HTML 模板中的 `{{ e.kind }}`。
- **密钥红线 / 安全分层**：未触及任何写接口与密钥存储。

## 5. 偏差与决策

- **D-M23-1（帮助页走静态文件而非新增路由）**：用户纪律要求「不碰 `.py` 后端逻辑」。新增 `/help` 路由必然改动 `routes/*.py`；
  故改为交付 `hpsl/static/help.html`，由既有 `StaticFiles` 挂载，导航链接指向 `/static/help.html`，**零后端改动**。
- **D-M23-2（显示翻译而非数据翻译）**：状态枚举值在多处被后端逻辑/状态机依赖，直接改枚举会触发 DDL 与行为风险；
  采用视图层共享宏翻译，单点维护、未知值兜底，彻底隔离风险。
- **D-M23-3（隐藏域保留原始值）**：工作流转移需后端按原始 `unit.status` 判定乐观锁（`expected_version`），故仅翻译可见文本，
  隐藏域 `value="{{ unit.status }}"` 维持原值，确保状态机正确。

- 未做 A/B 或可用性实测（无真人用户样本）；改造基于「成熟产品交互范式 + 通俗化」专家判断，建议上线后收集非技术用户反馈再微调。
