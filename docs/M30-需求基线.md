## 3. 关键契约

### 3.1 检索（P2-01）

- 索引：`POST /api/v1/sources {path}` → 只读挂载目录，仅 `.md/.txt/.markdown`，单文件 ≤1MB；返回 `{source_id, files, chunks}`。
- 查询：`GET /api/v1/search?q=&limit=` → `{hit, items:[{source_id,page,text,score}]}`；无命中 `hit=false`（页面显示「未检索到」）。
- 分词：优先 `jieba`；不可用则「中文 bigram + 英文词」确定性兜底；**索引与查询必须同一 tokenizer**。
- 删除：`DELETE /api/v1/sources/{sid}` → 同时清 `source` 行与 `chunk_fts`。

### 3.2 空白上下文（P2-02）

- `blank_context=true` 时角色上下文**只含 `learner_input`**（answer_machine 映射为 `question`）；
- `input-preview?blank_context=true` 返回的 `visible_fields` 不得含 `unit_title`/`concept_summary`。

### 3.3 多模型（P2-03/04）

- `cross-check`：每个模型各自调用、各自记账（`llm_call` N 行）与写 turn（2N 行）；返回并排答案。
- `critic/multi`：每个模型一条 `claim_check`，`providers` 标注 `critic/answer/same_source`。
- `rubric/verify`：第二条厂商模型核对评分要点，结果写入 `claim_check`（claim="评分要点核对"）。

### 3.4 治理（P2-05/06/07）

- `suggest_band`：严格按 风险>质量>节奏>进度 裁决，输出 `{band, plane, reason}`；样本不足不下结论。
- 衰减：`已验证`（≤2 天）→ `待验证`（≤7 天）→ `未验证`（>7 天），只读计算，不写库。
- 周盘点：列出 L2/L3 待补缺口；批量改状态（`已补/已验证/废弃`），逐条经 `db.write` 审计。

### 3.5 平台（P2-08/09/10）

- CSRF token 形如 `nonce.hmac_sha256(secret, nonce)`；篡改/不匹配 → 403。
- `serve()` 在密钥库锁定时，若为交互终端则 `getpass` 提示口令（`HPSL_NO_PASSPHRASE_PROMPT=1` 可禁用），否则打印提示继续。
- Anthropic 流式解析 `content_block_delta` 与 usage（统一为 `prompt_tokens/completion_tokens`）。

### 3.6 前端（P2-11/12）

- `.skip-link`、`main#main`、导航 `aria-current="page"`、tip `tabindex="0"`；
- 配额弹层 `role="dialog" aria-modal="true"` + 关闭按钮 + Esc；
- 表格 `th scope="col"`；
- graph 节点仅 `data-id`，点击由事件委托处理。

## 5. 明确的优化取舍

1. **jieba 缺失**：不引入新依赖（离线），用 bigram 兜底；再装 jieba 即自动启用。
2. **keyring 实测**：环境未安装 keyring，用 fake 模块验证优先链路，不做真实钥匙环集成。
3. **Anthropic 流式**：按 Messages API SSE 实现；无真实 key，用注入流验证解析。
4. **graph 内联 onclick**：仅移除这一处；按钮的 `onclick`（缩放/布局）保留。
5. **P2-06 衰减**：只在 API/详情展示层计算，不回写 `concept.verify_status`（避免与复测写回冲突）。
