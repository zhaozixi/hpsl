1. 这是什么东西

HPSL 是一个帮你自学的小工具。你告诉它「想学会什么」（比如「学会 Python 数据分析」），它会把这个大目标拆成许多小单元，一步步带着你：学 → 练 → 考 → 复习。它还会帮你记账（花了多少 AI 费用）、记笔记（卡片）、画关系图（概念图），让你清楚自己学到哪了、哪里还不会。

一句话：它像一个私人学习教练，把「我想学会」变成「我真的学会了」。

2. 第一次怎么开始（四步向导）

第一次打开，点导航栏的 向导，跟着四步走：

第 1 步 · 创建项目

填「项目名称」和「学习目标」。项目就是你想要学会的那件事。比如名称填「Python 数据分析入门」，目标填「能独立完成一份数据分析报告」。

第 2 步 · 填写模型密钥

选一家模型（如 DeepSeek、通义千问等），把你的 API 密钥 粘进去。密钥相当于模型的「登录密码」，从哪里买模型，就在哪里拿。填完点「保存密钥」。

第 3 步 · 测试连接

点「测试连接」，看看密钥和网络通不通。出现「连接成功」就说明没问题。

第 4 步 · 开始学习

点「进入单元学习」，正式开始。后面的学习流程系统会自动带你走。

提示：密钥只存在你本地，不会上传给任何人。不确定怎么拿密钥？问给你模型账号的人，或看模型官网的「API 密钥」页面。

3. 各个功能怎么用

单元

「单元」是你要攻克的一个个小知识点。列表里每个单元后面有个彩色小标签，表示它进行到哪一步（如「未开始 / 学习中 / 已完成」）。点单元名进详情。

第一次用先点「新建单元」：填单元标题（必填），难度档可选「稳妥 / 拉伸 / 回补」，点「创建单元」即可。

单元详情 · 推进学习

进去后看 ② 工作流：系统告诉你「当前状态」，并给你一个「推进到下一步」的按钮。每做到一定程度，就点一下，把单元往前推。就像过关一样，一步步走到「已完成」。

下面还有四块，按顺序用：③ 产出（先做出点东西再验证）、④ 记录一次尝试（重述/边界题的自评与确认得分）、⑤ 判定闭环（给分结束本单元）、⑥ AI 辅助（选一个角色把你的内容发给它）。

⑦ 缺口：列出你还不太懂的地方，分「轻微 / 一般 / 严重」三档，方便你优先补。

卡片

每当你验证通过一项内容，系统会生成一张要点卡片，写清关键结论。卡片是你自己的笔记，日后复习、回顾都靠它。

概念图

把学到的知识点画成一张关系网：每个圆点是一个「概念」，连线表示它们之间的关系（比如 A 是 B 的「前置知识」）。点圆点看详情，拖动摆放位置，滚轮缩放。

分析

用图表看学习进展：花费走势、概念验证时间线、各状态单元的分布。点「7 天 / 30 天…」可切换时间范围。

预算

调用 AI 模型会花钱。这里按「每次学习会话」统计花费，并用颜色提醒你：正常 绿色、临近上限 黄色、已超限 红色。红色时需要你点一下「确认继续」。

复测

学过的东西隔段时间容易忘。这里列出该复习的内容，点「开始复测」温习一下即可，不用从头再学。

设置

这里调「考试多少分算及格」之类的标准，系统已给好默认值，一般不用改。每个项目后面的「?」悬停能看通俗解释。留空 = 不改这项。

备份

点「导出当前库快照」，把全部学习数据存成一份存档。建议定期备份，换电脑也不怕丢。

导出

把当前项目的学习数据整理成一份 Markdown 文档，方便你保存、打印或分享给别人。

4. 界面名词对照表

界面上有些词你可能没见过，这里对照成日常说法：

界面上的词意思（大白话）
未开始 / INIT刚建立，还没开始动手
选题中 / PICK正在挑要攻克的知识点
学习中 / LEARN正在阅读、理解相关内容
产出中 / PRODUCE正在动手写出或做出点东西
验证中 / VERIFY正在检查自己的产出对不对
评判中 / JUDGE判断自己到底掌握没有
整合中 / INTEGRATE把新学的并入整体知识
已完成 / CLOSED这个学习单元已经结束
缺口你还没弄懂、需要补的地方
卡片验证通过后生成的要点笔记
概念图知识点之间的关系网
复测隔段时间回来巩固复习
预算 / 花费调用 AI 模型产生的费用
正常 / 临近上限 / 已超限花费在预算内 / 快到顶了 / 已超，需确认

5. 常见问题

点「向导」提示还没选项目？

先完成第 1 步「创建项目」，向导会自动切换到它。也可以回首页点「新建项目」。

测试连接失败？

多半是密钥填错，或网络不通。重新检查第 2 步的密钥，确认没多复制空格；仍不行就问给你模型账号的人。

花费变红了怎么办？

那是提醒你快超预算了。页面会弹窗请你「确认继续」，想继续就点确认；想省着用就在「设置」里调整预算上限。

数据会丢吗？

去「备份」点一下导出快照，数据就存下来了。建议定期备份。

还有看不懂的地方？回到页面，把鼠标悬停在带「?」的词上，会弹出通俗解释。
